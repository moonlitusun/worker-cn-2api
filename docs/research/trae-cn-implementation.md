# Trae CN 接入完成记录

日期：2026-10-26（Asia/Taipei）。接入范围：中国区 `solo_work_lite` 兼容聊天通道。

## 已实现

- 独立 `trae` 包：请求转换、具名 SSE 解析、同步聚合、工具参数分段合并、错误处理、动态目录和会话刷新。
- `/v1/chat/completions` 支持 `trae/<原始模型ID>`，保留 WorkBuddy 原有路由。
- `/v1/models` 合并已配置渠道；目录失败明确报错，不返回虚构模型。
- 管理页面支持凭据配置、可选刷新令牌与产品类型、脱敏显示、清空和热更新。
- 支持读取本机中国区桌面登录凭据的 `tc` AES 格式，使用对应产品 ClientID 刷新；轮换会话保存到本服务运行配置。
- 刷新与管理员修改凭据的保存过程串行化，防止旧会话覆盖新账号；保存失败后保留轮换会话并重试保存。
- 排队、刷新等待、目录等待和上游读取响应取消；错误和截断不会伪报正常完成。
- `cmd/trae-probe` 提供可重复执行的真实账号检查，不输出凭据。
- 管理后台支持强制新鲜目录的连接测试、短对话测试、有效期与续期状态、最近运行错误、模型搜索和渠道筛选。
- 支持保存多个命名账号、手动切换与删除，刷新结果同步到当前账号。这里不做自动账号轮询；详细操作见 [后台使用说明](../trae-cn-admin-guide.md)。
