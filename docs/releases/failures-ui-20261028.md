客户端请求取消与内部响应头计时取消分开判断；WorkBuddy/Trae 响应头和流空闲计时器保留明确超时原因；Qoder 已有 idle 原因也归类为超时。响应已开始后的流错误仍记录归类状态，HTTP 流本身不能重新设置响应头。
