# Trae CN 管理后台使用说明

更新：2026-10-26。

## 查看当前状态

登录 `/admin`，打开“渠道凭证”。Trae 卡片显示当前账号、令牌有效期、自动续期是否可用，以及正在处理和排队的请求数。

- “已配置 · 未验证”只表示有凭据，不代表上游接受该账号。
- “最近测试通过/失败”对应最近一次连接或对话测试。24 小时内到期会提示；已到期且有刷新凭据时，下一次请求会尝试续期。
- 最近连接测试、续期、目录和聊天记录包含时间、耗时和脱敏错误。这些是本次运行的记录，重启或切换账号后重新记录。
- 页面每 15 秒刷新状态，不会清空正在编辑的凭据，也不会自动发送模型聊天请求。

## 测试连接和对话

“测试连接”会强制重新获取当前账号的模型目录，绕过本地目录缓存；必要时先刷新会话。它不生成模型回复。

连接通过后，从模型选择框选择一个模型，再点击“测试对话”。这会发送一条请求模型回复 OK 的短消息，消耗少量额度，用于验证该账号是否真正能使用该模型。目录可见不等于有调用权限。

测试最长等待 60 秒。错误会显示在最近测试记录中；测试期间如果账号被切换，会提示重新测试。

## 更新凭据

填入原始 Cloud-IDE-JWT，不加 `Bearer` 或其他前缀。刷新凭据和访问令牌必须来自同一会话；产品类型按实际选择 Trae Code CN 或 TRAE SOLO CN。

保存凭据会替换当前账号的会话。刷新令牌留空意味着不保留旧刷新令牌；过期时间可填写 ISO 8601，也可由 JWT 的 exp 推导。界面不会回显访问令牌或刷新令牌。

自动续期成功后会将轮换会话写入运行配置。若写入失败，会显示等待重试保存；需检查配置文件写入权限。

## 管理多个命名账号

展开“已保存账号”：

1. 输入账号名称，点击“另存为新账号”。新令牌留空时保存当前会话；填入新令牌时保存表单中的会话。
2. 选择已保存账号，点击“切换到所选账号”，即时切换后续请求使用的账号。
3. 选择账号并修改名称或输入新的凭据，点击“更新并切换”。不填新令牌时保留该账号原凭据。
4. 删除所选账号时，若它正被使用，会同时停用当前 Trae 渠道；删除其他账号不会改变当前会话。

这是手动切换的账号管理，不做多账号自动轮询或故障转移。账号名称、会话与当前选择写入运行配置，自动续期也会同步更新当前保存的账号，避免切换回来时恢复旧令牌。

如果切换时正在续期，会先保存好原账号的新会话再切换；已经在处理的聊天请求可以按原会话结束。

“清空”会清除当前会话及当前已保存账号的凭据，其他保存账号不受影响。服务重启时仍会按既有优先级尝试环境变量或桌面登录凭据。

## 查看模型信息

“模型”页面支持按渠道筛选、搜索名称或 ID，以及复制调用 ID。模型发现统一展示 `workbuddy/` 和 `trae/` 前缀，不重复展示无前缀别名。旧的 WorkBuddy 无前缀聊天配置仍兼容。

卡片显示上游名称、上下文窗口、最大输出和函数工具能力。没有权威声明的字段显示“未声明”或“待验证”，不根据名称猜测。Trae 当前兼容聊天通道只支持文本输入，目录里模型自身具备视觉能力也不代表这个通道支持图片。

若某个渠道目录失败，管理页面会显示该渠道错误并继续展示其他成功渠道的目录。对外 `/v1/models` 保留严格行为：任何已配置渠道失败都会报错。

## 管理接口

以下接口均要求管理登录会话：

| 接口 | 用途 |
|---|---|
| `GET /admin/api/trae` | 脱敏凭据状态、有效期、自动续期与最近运行结果 |
| `POST /admin/api/trae` | 替换当前会话，保存后立即生效 |
| `DELETE /admin/api/trae` | 清空当前会话 |
| `POST /admin/api/trae/test` | `{}` 检查新鲜目录；`{"model":"原始ID"}` 追加短对话测试 |
| `GET /admin/api/trae/accounts` | 命名账号摘要，不返回令牌 |
| `POST /admin/api/trae/accounts` | `action=save/activate`，保存或切换账号 |
| `DELETE /admin/api/trae/accounts?id=...` | 删除指定账号 |
| `GET /admin/api/models` | 模型信息和按渠道区分的目录错误 |
